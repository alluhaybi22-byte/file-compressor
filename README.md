# ضَغطة

تطبيق ويب عربي لضغط الملفات في أرشيف ZIP. تتم معالجة الملفات داخل المتصفح ولا تُرفع إلى خادم. يُخزّن الملف دون ضغط إذا كان ضغطه سيزيد حجمه.

## التشغيل

من داخل مجلد التطبيق، شغّل خادماً محلياً:

```sh
python3 -m http.server 8000
```

افتح <http://localhost:8000> في متصفح حديث يدعم `CompressionStream`، واختر الملفات ثم اضغط زر التحميل. الحد الإجمالي للملفات المختارة 256 ميجابايت. يعمل التطبيق دون اتصال بالإنترنت.

## الاختبارات

```sh
npm test
```

## النشر على Cloudflare Pages

أنشئ ملفات الموقع فقط:

```sh
npm run build
```

بعد تسجيل الدخول إلى حساب Cloudflare باستخدام Wrangler، أنشئ مشروع Pages وانشر مجلد `dist`:

```sh
npx wrangler login
npx wrangler pages project create daghta
npx wrangler pages deploy dist --project-name daghta
```

إذا كان اسم المشروع مستخدماً، اختر اسماً متاحاً واستخدمه في الأمرين. يعرض أمر النشر رابط الموقع بعد اكتماله.
