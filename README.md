# ضَغطة

تطبيق عربي لضغط PDF أو جمع الملفات في ZIP. تتم معالجة الملفات داخل المتصفح؛ لا تُرفع ملفات المستخدم إلى خادم.

## ضغط PDF

- ملف واحد حتى 256 ميجابايت.
- ثلاث درجات: خفيف (170 DPI)، متوازن (120 DPI)، وقوي (85 DPI)، مع حد لذاكرة رسم الصفحة.
- إعادة رسم الصفحات وضغط صورها بصيغة JPEG؛ تناسب الملفات الممسوحة ضوئياً والمصوّرة.
- تعرض الواجهة الحجم قبل الضغط وبعده ونسبة التوفير ومعاينة الصفحة الأولى قبل تنزيل PDF.
- لا تُحفظ إمكانية البحث ونسخ النص والروابط والنماذج والتوقيعات الرقمية في النسخة المصوّرة. احتفظ بالأصل.
- إذا كانت النتيجة أكبر، لا تُعرض للتنزيل ويُقترح الاحتفاظ بالأصل أو اختيار ضغط أقوى.
- دعم الإلغاء ومعالجة الصفحات بالتتابع لتقليل استهلاك الذاكرة. قد تكون الملفات الكبيرة بطيئة على الأجهزة محدودة الذاكرة.
- لا يوجد حجم نهائي مضمون؛ يعتمد على محتوى المستند والجودة المختارة.

## ZIP

جمع مختلف أنواع الملفات في ZIP دون تغيير محتوياتها، بحد إجمالي 256 ميجابايت. يُخزّن الملف دون ضغط إذا كان ضغطه سيزيد حجمه.

## التشغيل

يتطلب البناء Node.js 22 أو أحدث. استخدم متصفحاً حديثاً.

```sh
npm ci
npm run build
python3 -m http.server 8000 --directory dist
```

افتح http://localhost:8000. يحتوي البناء على مكتبات PDF.js وPDF-LIB ومواردها محلياً؛ لا يعتمد التشغيل على CDN أو خدمات معالجة خارجية. تشغيل الملفات مباشرة عبر file:// غير مدعوم. يمكن استخدام النسخة المحلية دون إنترنت بعد تثبيت المتطلبات والبناء؛ الموقع المنشور يحتاج اتصالاً لتحميل موارده.

## الاختبارات

```sh
npm test
```

تشمل إنشاء ZIP قابل للفك، وضغط PDF مصوّر حقيقي بالدرجات الثلاث مع التحقق من عدد الصفحات واتجاهها، ومنع النتائج الأكبر، والتحقق من الملفات والإلغاء. تستخدم اختبارات الرسم @napi-rs/canvas، وهو اعتماد اختياري لـ PDF.js.
